    🧠 13-Step Problem Solving Framework & Thinking Checklist ▼
    1. Understand: What exactly is being asked?
    2. Input & Output: What data types enter and return?
    3. Small Example: Create a list of 3 items on paper.
    4. Solve Manually: How would you solve it with a pen?
    5. Brute Force: What is the simplest, most obvious loop?
    6. Pattern: Traversal? Counting? Two Pointers? Hashing?
    7. Pseudocode: Write the steps in plain English first.
    8. Dry Run: Step line-by-line with variables.
    9. Write Code: Keep syntax clean and readable.
    10. Test Edge Cases: Empty list? Negatives? Duplicates?
    11. Analyze Complexity: Time O(N)? Space O(1)?
