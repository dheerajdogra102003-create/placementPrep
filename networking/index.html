Core Placement Syllabus & Concept Map

Essential domains tested across 2025-2026 entry-level engineering drives:

OSI 7-Layer Reference Model Must Do

All 7 layers, PDUs (Bits, Frames, Packets, Segments), header encapsulation, troubleshooting bottom-up.

TCP/IP & Transport Layer High Weight

TCP 3-way handshake, TCP vs UDP tradeoffs, flow control vs congestion control, connection termination.

Network Hardware & Devices Core L1-L3

Hubs (L1), Switches & MAC CAM tables (L2), Routers & Routing tables (L3), Repeaters, Bridges, and Wireless APs.

Application Protocols & Ports Standard PYQ

HTTP (80), HTTPS (443), SSH (22), DNS (53), DHCP DORA (67/68), SMTP (25), POP3 (110), IMAP (143).

IP Addressing & Subnetting Numerical

IPv4 vs IPv6, MAC vs IP, RFC 1918 Private ranges (10.x, 172.16.x, 192.168.x), 2^H - 2 host calculations.

Step-by-step: Cache check -> DNS resolution -> TCP Handshake -> TLS Handshake -> HTTP GET -> HTML Render.
