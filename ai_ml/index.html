⚡ AI, Machine Learning & Deep Learning Placement Cheatsheet

1. Model Evaluation & Confusion Matrix

Scikit-Learn Confusion Matrix:
[[True Negative (TN), False Positive (FP)],
[False Negative (FN), True Positive (TP)]]
Accuracy: (TP + TN) / (TP + TN + FP + FN)
Precision: TP / (TP + FP) (Critical when False Positives are costly: Spam Filter)
Recall (Sensitivity): TP / (TP + FN) (Critical when False Negatives are costly: Cancer/Fraud)
F1-Score: 2 * (Precision * Recall) / (Precision + Recall) (Harmonic mean)

2. Decision Trees & Clustering

Gini Impurity: Gini = 1 - Σ(p_i^2) (Max binary Gini = 0.50 at 50/50 split; Pure node = 0.0)
Entropy: H(S) = - Σ (p_i * log2(p_i))
Information Gain: Gain(S, A) = Entropy(S) - Σ (|S_v| / |S|) * Entropy(S_v)
IQR Outlier Formula: IQR = Q3 - Q1; Outliers lie outside [Q1 - 1.5*IQR, Q3 + 1.5*IQR]

3. Deep Learning & Neural Networks

Dense Layer Parameter Count: (Num_Inputs + 1) * Num_Neurons (+1 for bias)
CNN Output Feature Map Dimension: Output = floor((Input_Size - Filter_Size + 2*Padding) / Stride) + 1
Gradient Descent Update: w_new = w_old - η * (dL / dw)
L1 vs L2 Regularization:
• L1 (Lasso): Adds λ * Σ|w| -> Drives non-important weights strictly to 0 (Sparse feature selection).
• L2 (Ridge): Adds λ * Σ(w^2) -> Shrinks weights asymptotically toward 0 (prevents exploding weights).

4. Common Placement Interview Traps

• Accuracy Paradox: On imbalanced data (99% class 0, 1% class 1), a dumb model predicting 0 gets 99% accuracy. Always use ROC-AUC, F1-Score, or Precision-Recall curves instead.

• Data Leakage: Calling scaler.fit() on the whole dataset before splitting leaks test distribution information. Always split first, fit only on training data, and transform test data.

• Dummy Variable Trap: When one-hot encoding a categorical feature with k categories, only include k - 1 dummy columns in linear regression to avoid perfect multicollinearity.

• Vanishing Gradients: Sigmoid derivative maxes out at 0.25. Deep stacking causes gradients to multiply to ~0. Remedy: Use ReLU activations and Batch Normalization.
