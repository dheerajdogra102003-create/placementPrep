03 / RAPID RECAP

LAST-HOUR REVISION

High-yield technical comparisons, formula strips, and critical exam traps to read before entering your interview or screening test.

Concept Comparison Tool / Command A Tool / Command B Exam Distinction & Trap
Git vs GitHub Git: Local distributed VCS engine installed on machine. GitHub: Cloud-based hosting & collaboration platform. Git works 100% offline. Commits, branch creation, and logs do not require GitHub.
git fetch vs git pull git fetch: Downloads remote refs into tracking branches without merging. git pull: Runs fetch AND immediately merges into local working branch. pull = fetch + merge. Interviewers check if you know fetch never touches your working tree.
git reset vs git revert git reset: Moves branch pointer backwards, rewriting commit history. git revert: Creates a new commit inverting historical changes safely. Never reset shared public branches! Always use revert on team branches (main/staging).
Fork vs Clone Fork: Remote copy on GitHub servers under your user account. Clone: Download full repository from remote server to local machine. Fork has no native Git CLI command; it is a GitHub platform feature used for open-source PRs.
.gitignore Traps Untracked files: Ignored completely by Git status and add. Already committed files: Git continues tracking even after added to .gitignore! To untrack already committed file: run git rm --cached <file> then commit.
01 MUST KNOW

High-Frequency Commands

The core commands expected in every MNC fresher screening.

git status # Check working & staged state git log --oneline # Compact single-line history git diff --staged # Diff index against HEAD git mv old.js new.js# Rename tracked file cleanly
• git diff shows unstaged changes; git diff --staged shows staged changes.
02 MUST KNOW

Git Three-Tree Lifecycle

File transition states from disk to commit.

Working Tree → git add → Staging Area (Index) Staging Area → git commit → Local Repo (HEAD) Local Repo → git push → Remote Repo
• A file can be partially staged and unstaged at the same time.
03 MUST KNOW

Branch Creation & Switch

Modern branch management commands.

git checkout -b feature-auth # Create and switch git switch -c feature-auth # Modern 2.23+ syntax git branch -d feature-auth # Safe delete (checks merge) git branch -D feature-auth # Force delete unmerged
• HEAD is the pointer to your currently checked-out branch reference.
04 MUST KNOW

Conflict Resolution Steps

Step-by-step resolution protocol.

1. Open conflicting file; inspect <<<<<<< HEAD vs ======= 2. Keep desired code; delete all conflict markers 3. git add <file> (marks conflict resolved) 4. git commit (finalizes merge commit)
• To abort an in-progress merge conflict cleanly: git merge --abort.
05 HIGH PRIORITY

Non-Fast-Forward Push

Handling rejected pushes when remote has newer commits.

# Error: [rejected] (non-fast-forward) git pull origin main # Integrate incoming changes # resolve any merge conflicts if they arise git push origin main # Push successfully
• Never force push (git push -f) to shared main! It destroys team commits.
06 HIGH PRIORITY

Open Source PR Workflow

Contributing when you have no direct write permissions.

1. Fork repo on GitHub → clone personal fork locally 2. git remote add upstream <original-repo-url> 3. Create feature branch → commit → push to origin 4. Open Pull Request on GitHub to upstream main
• Upstream = original parent repo; Origin = your personal fork.
07 HIGH PRIORITY

Untracking & Leaked Keys

Fixing committed secrets and untracking files safely.

git rm --cached .env # Untrack without deleting disk file git commit -m "Untrack .env file" # If AWS key was pushed publicly: # REVOKE and ROTATE key immediately in cloud console!
• Deleting a secret in a new commit does NOT erase it from Git history.
08 MUST KNOW

Reset Modes & git reflog

Safe recovery after accidental resets.

git reset --soft HEAD~1 # Keeps changes staged git reset --mixed HEAD~1# Default: keeps changes in working tree git reset --hard HEAD~1 # Discards everything git reflog # Shows safety audit log to recover lost SHAs
• git reflog records every movement of HEAD, even after hard resets!
